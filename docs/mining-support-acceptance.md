The dispatch race had a uniquely provable result. Ambiguous outcomes retain
hosted control and block duplicate mutation/resume; that safety contract is
mechanically tested. A deliberately forced ambiguous live outcome was not tested.
ACKs are not physical postconditions or proof of can/fleet identity.

Jettison recovery is a narrow same-process hosted exception. The generated miner
retains `restartSafe:false`; other destructive scripts keep their existing gates.
Read [jettison-custody.md](jettison-custody.md) for exact provenance and custody.

**PROCESS-RESTART JETTISON RECOVERY NOT IMPLEMENTED.** Custody is volatile
run-scoped host memory; full WC interruption has no durable mutation journal.
Persisted records do not become eligible for unsafe restart replay.

The local acceptance environment used the cumulative clean-reference Mining
Support runtime observation package composed with its existing unrelated runtime
extensions. Clean-reference artifact hashes describe clean EveJS 0.12.9 and the
published helper payloads, never a deployment-specific mutable runtime.
