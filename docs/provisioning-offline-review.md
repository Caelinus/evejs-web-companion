# Offline provisioning boundary

Standalone offline roster/equipment Review and Apply are unavailable on stock EveJS. Stock snapshot cannot prove complete stable inventory/source observations, and stock selection is not atomic free-only acquisition. WC returns PROVISIONING_OFFLINE_AUTHORITY_UNAVAILABLE before any selection. It does not label an incomplete snapshot VERIFIED.

Select a pilot at an NPC station and use Ready Fit, Provision Ship or Replenish. MCC verifies equipment under each final hosted owner. Historical Center invocation evidence remains readable; release recovery uses positive exact stock offline status and preserves pending custody/foreign reservations.

LEGACY — DO NOT DEPLOY: offline projection/install scripts and core helpers were removed from the active tree. Git history is provenance only. See [stock integration policy](stock-evejs-integration-policy.md).
